# Drone-project-based-on-STM32

## 1. 项目介绍

### 1.1 综述

此项目的原型是尚硅谷无人机项目教程。本人根据该原型迭代与调试，并在此基础上进行了一些**逻辑与功能上的优化**，也增加了一些**新的功能**，使之更加易懂易用。同时为了提升本项目代码部分的可读性，本人在项目的代码中加入了**更详细的说明**，以便于其他开发者阅读与理解。

> **本项目截止目前仍然在开发中，后续会根据实际需求进行迭代与优化。**

## 2. 项目运行

### 2.1 环境准备

- **Keil MDK5**（必须）
- **STM32CubeMX**（可选，用于自主调试时生成代码）
- **VS Code**（可选，用于优化代码编写体验）

---

### 2.2 运行步骤

#### 2.2.1 环境准备（详细）

##### 安装 Keil MDK‑ARM（若未安装）

- 安装 [Keil MDK‑ARM](https://www.keil.com/download/product/)（版本 5.0 及以上）。
- 安装过程中请确保勾选 **STM32F1 系列支持包**，或后续通过 Pack Installer 手动安装：
  - 打开 Keil，点击 `Pack Installer` 按钮。
  - 在 `Devices` 搜索 `STM32F103`（本项目适配芯片具体型号为 STM32F103C8T6），点击 `Install` 安装 `Keil.STM32F1xx_DFP` 包。

##### 准备硬件

- **官方购买链接**：[飞机本体 + 遥控器](https://e.tb.cn/h.8dxjhQnxAMEf27j?tk=UyxHgFQpvYE)
- **个人打板、焊接**：打开 `PCB_files` 文件夹，按 Gerber 文件下单打板（推荐使用嘉立创下单助手），按物料清单购买元件，自行完成焊接。

---

#### 2.2.2 编译工程

本项目包含两个独立工程，需分别编译：

- `P01_flight_hal` —— **无人机飞控**
- `P02_remote_hal` —— **遥控器**

##### 打开工程

1. 进入对应工程目录：
   - 无人机：`Drone-project-based-on-STM32-main/P01_flight_hal/MDK-ARM/`
   - 遥控器：`Drone-project-based-on-STM32-main/P02_remote_hal/MDK-ARM/`
2. 双击 `P01_flight_hal.uvprojx` 或 `P02_remote_hal.uvprojx`，Keil 将自动打开工程。

##### 选择编译目标

- 在 Keil 工具栏的 `Target` 下拉菜单中，确认选择 **`P01_flight_hal`**（无人机）或 **`P02_remote_hal`**（遥控器）对应的目标名称（通常已默认选中）。

##### 编译

- 点击工具栏的 **`Build`** 按钮（或按 `F7`）开始编译。
- 若编译成功，底部 `Build Output` 窗口会显示 **`"0 Error(s), 0 Warning(s)"`**，并生成 `.axf` 和 `.hex` 文件（位于 `MDK-ARM/P01_flight_hal/` 或 `P02_remote_hal/` 输出目录）。

---

#### 2.2.3 烧录固件

##### 连接烧录器

- 将 ST‑Link / J‑Link 连接到电脑 USB 口，另一端连接到无人机 / 遥控器主板的 **SWD** 接口（通常为 SWCLK、SWDIO、3.3V、GND）。
- 给无人机 / 遥控器主板**上电**（通过电池供电，无人机电池型号为 603048 3.7V 2000mAh，遥控器为 902731 3.7V 500mAh）。

##### 配置烧录器

1. 在 Keil 中点击 **`Options for Target`**（魔术棒图标）或按 `Alt+F7`。
2. 切换到 **`Debug`** 选项卡：
   - 在右侧 `Use` 下拉列表中选择你的烧录器（如 `ST-Link Debugger`）。
   - 点击 `Settings`，确认能正确识别芯片（显示 `STM32F103x` 系列）。
3. 切换到 **`Utilities`** 选项卡：
   - 确保勾选 `Use Debug Driver`，并选择与 Debug 相同的烧录器。
   - 点击 `Settings`，在 `Programming Algorithm` 中添加 `STM32F10x Med-density Flash`（若已存在则无需操作）。

##### 执行烧录

- 点击工具栏的 **`Load`** 按钮（或按 `F8`）开始下载。
- 烧录成功后，`Build Output` 会显示 **`"Application running..."`** 或烧录完成信息。

---

#### 2.2.4 运行与调试

##### 首次运行

- 烧录完成后，开发板会自动复位并运行固件。
- 若没有自动运行，可手动按一下板上的 **复位按键**（若有），或重新上电。

##### 串口调试（可选）

- 项目中使用了 `common` 模块的调试打印功能（通过串口）。
- 将 USB 转串口模块连接到主板的 **USART1**（TX/RX），波特率默认 **115200**。
- 打开串口调试助手（如 PuTTY、SecureCRT），即可查看飞控 / 遥控器的运行日志。
- 若烧录器选用的是PCB文件中同款，则只需将其一端通过USB数据线插入电脑USB口，另一端插入开发板的烧录接口，即可同时完成烧录与串口调试。

##### 调试模式

- 点击 **`Start/Stop Debug Session`**（放大镜图标）进入调试模式。
- 可设置断点、单步执行、查看变量和寄存器，便于定位问题。

---

#### 2.2.5 注意事项

- **两个工程独立**：无人机和遥控器必须分别编译和烧录，两者通过 2.4G 无线模块（SI24R1）通信。
- **电源管理**：若使用 IP5305T 电源管理芯片，请确保电池电压正常，否则飞控可能无法启动。
- **FreeRTOS 配置**：工程默认使用 FreeRTOS，任务优先级和堆栈大小已预配置，若无特殊需求请不要修改。
- **若编译报错**：
  - 检查 Keil 是否安装了 STM32F1 支持包。
  - 检查工程路径是否包含中文字符或空格（可能导致编译器异常）。
  - 尝试执行 `Rebuild All`（全部重新编译）清除中间文件。

---

#### 2.2.6 常见问题

**Q：烧录时提示 “No Cortex-M SW Device Found”**  
A：检查 SWD 接线是否正确，目标板是否上电，烧录器驱动是否安装成功。

**Q：烧录后程序无反应**  
A：确认电源正常，且 BOOT0 引脚接地（从 Flash 启动）。若使用 ST‑Link，可尝试在调试设置中降低 SWD 时钟频率。

**Q：串口无打印信息**  
A：检查串口线连接是否正确（TX → RX，RX → TX，GND 相连），波特率是否与代码中一致（默认 115200）。

### 2.3 运行结果

#### 2.3.1 飞机使用说明

- 首次运行飞机时，应短按两下电源按键将飞机关机，然后再次短按电源键开启无人机，确保硬件设备正常完成初始化。重启时应将飞机放置平稳表面，保证陀螺仪完成零偏校准。待下面两个led灯**持续慢闪**时，即代表飞机正常启动。

- 若依据硬件指导文件制造出的无人机或者官网购买的无人机为**新一代**版本，该版本更新了一个方便使用的复位按键，其余所有功能**不变**。首次运行无人机时，在重启完成后，可以按一下复位按键确保程序按正常时序进行。

#### 2.3.2 遥控器使用说明

- 飞机正常启动后，按下遥控器左下角开机键，可观察到飞机前两个led灯常亮。

- 遥控器左边摇杆上下控制油门，左右控制偏航角=>旋转角度。右边摇杆上下控制俯仰角=>前后飞行，左右控制横滚角=>左右飞行。将遥控器左边摇杆拨到上极位保持1秒，再拨到下极位保持1秒，可观察到无人机后两个led灯**持续快闪**，此时即可开始控制飞机飞行。

- 遥控器控制飞机之前应进行**零偏校准**，将油门拨到下极位并长按右上角按键1秒再松手即可完成遥控器校准。

- 遥控器左边摇杆越往上，飞机上升速度越快，反之越慢。短按右上角按键可以使无人机定高，即保持当前高度不变。左右拨动左边摇杆可改变飞机飞行朝向。对于右边摇杆，左右拨动可控制飞机往左往右飞行，上下拨动可控制飞机往前往后飞行。拨动幅度越大，控制效果越明显。

- 遥控器显示屏上第一行会显示标题，第二行会显示通信信道与无人机剩余电量。当电量低于**3.6V**时有概率会出现遥控器**失联**现象，同时也**不建议**在低于此电量的情况下飞行无人机，以确保安全与电池使用寿命。显示屏剩余空间会以**白块**的方式显示各个方向的控制幅度，白块越多，控制幅度越大。某方向显示的幅度与初始幅度相差越大，表示该方向控制幅度越大，反之越小。

- 若遥控器中途失联，无人机会启动故障处理程序，自动下降至地面。

- 若想结束飞行，请务必确保无人机**稳定停靠于地面**，**短按遥控器左上角按键**或者**短按两次无人机电源键**即可将无人机关机。若想在飞行中途结束飞行而不想关机，可以通过**长按左上角按键**使得飞机缓降至地面，当四个叶片不再转动且飞机下面两个灯**恢复慢闪**时，说明缓降程序结束，可再次解锁油门进行飞行。缓降途中遥控器执行的任何操作均**无效**。

- 当飞机电量**小于3.28V**时，遥控器显示屏会在原本显示电量的位置闪烁显示"F_BAT_LOW"(飞机电量低)字样，此时飞机会自动缓降至地面，且只要显示屏上"F_BAT_LOW"字样持续闪烁，遥控器进行的任何操作就均视为无效。只有将飞机充电至充足电量后才能继续正常飞行。同时也需要注意遥控器右下角led灯**只剩一个**常亮时，代表遥控器电量过低，也需要立刻充电。

- 飞行途中用户应确保无人机尽量减少磕碰，延长使用寿命。
